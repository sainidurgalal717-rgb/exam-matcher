🧩 हर feature असल में काम कैसे करता है
  • ✓Content-based matching: प्रश्न का text normalize करके token + character-similarity से मिलान किया जाता है, इसलिए Set A का Q.12 सेट B के Q.4 से match हो जाता है।
  • ✓PDF + Image दोनों: digital PDF का text सीधा पढ़ा जाता है; scanned PDF या photo पर browser में ही OCR चलता है।
  • ✓Hindi + English: दोनों भाषाओं के प्रश्न और Devanagari numbers support करते हैं।
  • ✓OMR mode: student का OMR sheet और official OMR answer key — दोनों अलग upload करके तुलना।
  • ✓Manual confirm: हर row में अपना answer बदल सकते हैं, score तुरंत re-calculate होता है।
  • ✓Marking scheme: +1 / negative marking / total marks अपनी मर्ज़ी से set करें।
  • ✓100% private: कुछ भी server पर नहीं जाता, सारा काम आपके device पर।
